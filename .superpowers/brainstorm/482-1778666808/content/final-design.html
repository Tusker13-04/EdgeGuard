Migration Design Specification

Finalizing the Arduino UNO Q Architecture

MCU (STM32U585)

  • Framework: Arduino
  • Loop: 400Hz Sensor Polling
  • Link: Bridge.notify() @ 460800 Baud
  • Sensors: LIS3DH (Qwiic), DS18B20 (D4)

MPU (QRB2210)

  • OS: Debian Linux
  • Ingest: Bridge RPC Listener
  • Buffer: numpy CircularBuffer
  • Inference: ONNX Runtime (2Hz)
Payload Contract (24 Bytes)
uint32_t  timestamp_us
uint32_t  sequence_id
float     accel_x
float     accel_y
float     accel_z
float     board_temp
