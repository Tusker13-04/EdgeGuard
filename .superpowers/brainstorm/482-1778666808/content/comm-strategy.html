Communication Strategy: Batching vs Latency

Optimizing Bridge RPC over UART

A

High Efficiency (Batch 25)

  • 16 RPC calls/sec
  • Fits 115200 Baud
  • ~62.5ms buffer latency
  • Lowest CPU/UART overhead
B

Low Latency (Small Batches)

  • ~100+ RPC calls/sec
  • Requires 460800 Baud
  • ~10-20ms buffer latency
  • Higher CPU overhead for interrupt handling

Recommendation

Option A (Batch 25) is recommended. The inference engine runs at 2Hz (500ms intervals), so a 62.5ms ingestion delay is negligible while ensuring rock-solid stability at default baud rates.
