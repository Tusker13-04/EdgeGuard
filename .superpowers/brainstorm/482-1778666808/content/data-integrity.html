Handling Sequence IDs in a reliable link

A

Keep sequence_id

Continue tracking monotonic counter. Useful for detecting MCU-side FIFO overflows or loop stalls, even if the UART link itself is reliable.

B

Remove sequence_id

Assume reliability. Reduces sample size from 24B to 20B. Frees up bandwidth for higher sample rates if needed later.

Context

The PacketParser currently uses this ID to calculate drop_rate_pct displayed on the dashboard.
