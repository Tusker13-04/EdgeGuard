MCU Development Framework

Choosing the programming environment for STM32U585

A

Arduino Framework (Recommended)

  • Reuse existing Adafruit_LIS3DH & DallasTemperature libs
  • Standard setup() / loop() structure
  • Fastest migration (~1 day)
B

Zephyr RTOS

  • Native real-time kernel with threading
  • Industrial grade stability & power management
  • Significant rewrite needed (Device Tree, new APIs)

Impact

Option A allows us to literally copy-paste the sensor logic and only swap the transport layer. Option B would be a ground-up rebuild of the firmware.
